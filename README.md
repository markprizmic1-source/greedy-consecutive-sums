## 1. Uniform bounds for greedy sequences avoiding consecutive sums

Starting at 1, choose each next larger integer greedily while excluding sums of a fixed number of consecutive earlier terms. For a window length $r\ge2$, define

$$b_j=\sum_{t=0}^{r-1}a_{j+t},\qquad C_r=\frac{r(r-1)}2-1.$$

The original note proves, for every $j,n\ge1$,

$$(r+1)j\le b_j\le(r+1)j+C_r,$$

and

$$\left\lfloor\frac{(r+1)n-C_r-1}{r}\right\rfloor\le a_n\le\left\lfloor\frac{(r+1)n-1}{r}\right\rfloor.$$

For [A394676](https://oeis.org/A394676), set $r=4$:

$$\boxed{\left\lfloor\frac{5n-6}{4}\right\rfloor\le a_n\le\left\lfloor\frac{5n-1}{4}\right\rfloor.}$$

In particular, $a_n/n\to5/4$. The general selected set has natural density $r/(r+1)$. The proof uses the complementary partition into selected terms and forbidden sums, followed by strong induction with the boundary cases included.

## 2. Fibonacci layers generated by doubling and two reflections

Start with $G_1=\{1\}$ and apply $x\mapsto2x$, $x\mapsto1-x$, and $x\mapsto2-x$ to each layer, removing every integer encountered earlier. Every integer appears in exactly one layer. With $F_0=0$ and $F_1=1$,

$$|G_n|=2F_{n-1},\qquad |G_n\cap\mathbb Z_{>0}|=F_{n-1}\quad(n\ge2).$$

For $n\ge4$, the even and odd counts are $2F_{n-2}$ and $2F_{n-3}$. The initial parity exceptions are stated explicitly in the paper. The proof establishes an exact shortest-path distance and the generating function $1+2z/(1-z-z^2)$.

[Paper and reproducibility instructions](papers/a242364-fibonacci-layers/README.md) · [Original problem: OEIS A242364](https://oeis.org/A242364)

## 3. Exact long equality runs in A394676

Put $U_n=\lfloor(5n-1)/4\rfloor$. All maximal equality runs $a_n=U_n$ of length at least four are exactly

$$\left[\frac{7\cdot16^m-2}{5},\frac{12\cdot16^m+8}{5}\right]_{\mathbb Z},\qquad m\ge0.$$

Their lengths are $16^m+3$. The first five intervals are $[1,4]$, $[22,40]$, $[358,616]$, $[5734,9832]$, and $[91750,157288]$. The last three correct the displayed endpoints in the retrieved OEIS entry. Every other maximal equality run has length at most three. The note includes all arguments needed for this classification.

[Paper and reproducibility instructions](papers/a394676-equality-runs/README.md) · [Original problem: OEIS A394676](https://oeis.org/A394676)

## Reproduce the computations

The scripts require Python 3.10 or later and use only the standard library. From the repository root:

```bash
# Original uniform-bound note
python3 -m unittest discover -s code -p 'test_*.py' -v
python3 code/verify.py --terms 200000 --window 4 --output results/window4_200000.json

# Fibonacci layers: all 392,835 integers through distance 25
python3 papers/a242364-fibonacci-layers/verify_distance.py --max-distance 25 --edge-radius 100000 > papers/a242364-fibonacci-layers/verification.json

# Equality runs: 400,000 terms of the original greedy sequence
python3 papers/a394676-equality-runs/verify_runs.py --terms 400000 --output papers/a394676-equality-runs/verification.json
```

Other fixed window lengths can be checked with the original program:

```bash
python3 code/verify.py --terms 10000 --window 7
```

Generation follows the original definitions without using the new theorems to choose terms or discover layers. The retained reports check implementation consistency; they are finite computations, not formal proof certificates. Run the checkers without Python's `-O` option so assertions remain enabled.
